# 结算计算单一来源：monorepo 共享 rules 包

点数计算（番×符→点数、满贯档位、亲/子系数、头跳）是一段**纯函数**，前端需实时预览、后端需落库校验。采用 pnpm monorepo，把这段逻辑抽到 `packages/rules`，web 与 api 共同 import，保证只有一份实现。

理由：结算计算正确性是本工具的核心（见 ADR-0001「点数计算器」）。若前端、后端各写一套，极易出现实时预览与落库结果不一致；单一来源从根上消除这类 bug，也让规则变更只改一处。

代价：引入 monorepo 与 workspace 结构，比两个独立目录略复杂；共享包改动需同时照顾 web / api 两侧。
