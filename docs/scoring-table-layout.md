# 计分风盘 — 布局与排版设计

> 版本 v0.16。配套：`docs/requirements.md`（功能规格）、`CONTEXT.md`（术语）。
> v0.16 变更：上/下座位条带加 min-height，高度与左右竖条宽度大致持平（四边块区厚度均衡）。
> v0.15 变更：中央上部三键（返回/终局/罚符）按钮与字号加大，与中央信息拉开更大间距防误触。
> v0.14 变更：移除顶栏，返回/终局/罚符移入中央区上部（罚符合并为单个按钮）、模式·局数类型并进中央；本场数与立直棒数拆两行；座位条带只剩荣和/自摸；按钮与骰子加大间隔防误触。
> v0.13 变更：字号/块区全量流式缩放（clamp+vmin，屏幕越大字号越大）；座位名钉左上角、座风居中加大；中央骰子/字号加大；pad 绿呢铺满整屏。

## 1. 设计目标

- **一眼读出「谁领先、谁是庄、现在第几局」**：点数、庄家、场风局数是最高优先级信息。
- **结算快**：结算是最频繁操作，每个座位自带「荣和/自摸/罚符」按钮，点即预选该座位并进入结算。
- **方位直觉**：环绕布局（上/左/下/右围中央）天然对应东南西北，换庄时不让人「跳」。
- **文字朝外**：每个座位条带按位置旋转，文字朝向各自玩家（手机平放牌桌中央的记分本形态）。
- **移动端竖屏优先**，大按钮大数字，适配线下打牌场景。

## 2. 布局结构

**环绕条带 + 中央块区**：绿呢平铺整个风盘界面（无四周留白、无正方形约束）。上/下为全宽横条，左/右为竖条，中央块区放公共信息与整桌操作（返回/终局/罚符在上、流局在下）；无顶栏。

```
┌────────────────────────────────┐
│     上家 (180°) 横条            │
│   名·点 · [荣和][自摸]          │
├──────┬───────────────┬─────────┤
│ 左家  │ [←返回][终局][罚符] │  右家 │
│ 90°  │  四人 · 半庄战    │ −90°  │
│ 竖条  │    東2局         │  竖条  │
│      │    2 本场         │       │
│      │   立直棒 3        │       │
│      │     ⚀ ⚁          │       │
│      │     [流局]        │       │
├──────┴───────────────┴─────────┤
│     下家 (0°) 横条             │
│   名·点 · [荣和][自摸]          │
└────────────────────────────────┘
```

### 2.1 全屏铺满

- 牌局**进行中自动隐藏底部标签栏**（沉浸式）；开局页与终局后仍显示标签栏。进行中中央区「返回」键重新显示标签栏、仍停留在计分风盘。
- 绿呢铺满整个风盘界面，四周无边距；尺寸按真实视口计算（`dvh`），不依赖固定像素预算。
- pad（≥768px）计分风盘绿呢**铺满整个视口**（该页解除 `#root` 的 max-width 上限）；手机仍按现有窄列。字号随 `vmin` 流式放大，无需另设断点。
- 上/下条带横向拉伸铺满整行（高度随内容自适应）；左/右为竖条（`1fr` 弹性宽度）；不再保持正方形。

## 3. 座位模型

- **座位固定**：四个屏幕座位（上/右/下/左）固定对应桌子的四个物理方位。
- **文字旋转**：整条随位置旋转——下 `0°`、右 `−90°`、上 `180°`、左 `90°`（文字/按钮朝外朝向该玩家）。
- **标签旋转**：换庄时只有「自风标签」在座位间旋转、庄家徽章跟着走；**人不跳**。
- **无「我」视角**：四方位客观固定；谁坐哪由开局「位置调整 / 随机分位」确定。

## 4. 座位条带

每条带内容（整体随位置旋转）分三段：座风与玩家信息、分数分差、底部按钮。

```
 🖼 雀士名          [東]      ← 玩家信息（钉左上角）· 座风（居中、大号）
         +3000               ← 对家分差（小字，+领先 / −落后）
  -1200  25000  +500         ← 分数 + 分差居中（大号）
  [荣和]    [自摸]            ← 底部：结算按钮（二等分平铺）
```

- 座风：`東 / 南 / 西 / 北`（繁体），换庄时旋转；**東即庄家**，不另设庄家徽章（庄家仅以卡片红框高亮识别）。座风**居中、大号**（不再是左上小徽章）。
- 玩家信息：头像 + 名称，**钉块区左上角**（不再居中于座风下方）。
- 点数：素点，大号粗体、居中，最高视觉权重。
- **分差**：围绕素点的小字，`我 − 对方`；对家在上、上家在左、下家在右（三人局无对家、只显示左右；二人局只有对家、只显示上方）。`+` 领先、`−` 落后、相等 `0`；变化带滚动数字动画。
- **结算按钮**：荣和 / 自摸，底部二等分平铺、各占 1/2 宽度（间隔防误触）；罚符移入中央区。
- **立直**：点击素点数字切换立直状态，供托 ±1 立直棒；立直时**块区背景变蓝**（`#3b82f6`）、名称/分数/分差文字变白。

## 5. 中央区

中央块区显示当前牌局公共状态 + 整桌操作，自上而下：

```
 [←返回] [终局] [罚符]    ← 上部：公共按钮（罚符就一个）
       四人·半庄战        ← 模式 · 局数类型（原顶栏并入）
        東2局            ← 大字「场风 + 局数」
        2 本场           ← 本场数（单独一行）
       立直棒 3          ← 立直棒根数（单独一行）
         ⚀ ⚁            ← 骰子（点击掷，与上下按钮加大间隔）
         [流局]          ← 流局按钮（整桌结果，保持在下部）
```

- **本场数**与**立直棒数**分两行显示（取根数，不显示点数）。
- **流局**放这里：流局是整桌结果（无人和牌）、无座位归属，与终局区分开。
- 返回/终局/罚符三键在中央上部、流局在下部；按钮与骰子之间加大间隔防误触。

## 6. 顶栏（已移除）

进行中不再有独立顶栏：返回、终局移入中央区上部，模式 · 局数类型也并进中央区。开局页靠底部标签栏导航（无需顶栏）。

## 7. 结算入口

- **每座位两个按钮**：`荣和 / 自摸`，点击 = 预选该座位并弹对应面板（省一次点选）：
  - 自摸 → 该座位预选为和牌者，面板里点「番符」字段选番符。
  - 荣和 → 该座位预选为**和牌者**，面板里再选放铳者 + 番符；多家荣和在面板里各自选番符。
- **罚符** → 中央区上部单个按钮，弹罚符面板，面板内选被罚雀士 + 罚点数 + 分配方式（各家均分 / 庄家得半）。
- **番符得点表**：点「番符」字段弹出表格——番 1~4 为「符行 × 番列」网格（格内分数），满贯封顶的符按番合并为「满贯」一格（边界随切上满贯开关）；下方满贯档位区（5番满贯 / 6~7番跳满 / 8~10番倍满 / 11~12番三倍满 / 13番役满 / 26番双倍役满）。表格自动区分亲/子、荣/自摸：荣和单数、亲家自摸 `X all`、子家自摸 `X,Y`（子付,亲付）；荣和隐藏 20符行，20符/25符的 1番显示 `-` 不可选。
- **流局** → 中央块区按钮，弹流局面板（不听罚符 / 途中流局 / 流局满贯）。
- **面板随座位旋转**：三按钮面板与「番符得点表」均按触发座位旋转（上 180°/左 90°/下 0°/右 −90°），与卡片方位一致；流局面板（中央触发）不旋转。
- 不再有底部共享四选一结算栏。

## 8. 状态与高亮

| 状态 | 表现 |
|---|---|
| 庄家 | 座位条带边框高亮（朱赤）；东即庄家，不设庄家徽章 |
| 立直中 | 块区背景变蓝（#3b82f6）、文字变白，供托自动 +1 根 |
| 结算选中 | 被选中的和牌者/放铳者座位高亮 |

## 9. 三人 / 二人适配

- **三人**：上 / 左 / 右（去正下方），旋转 `180° / 90° / −90°`（无 0° 座位）。
- **二人**：上 / 下，旋转 `180° / 0°`。
- 中央、顶栏、流局按钮不变；空位留绿呢。

## 10. 位置调整 / 随机分位（开局时）

- **随机分位**：一个「随机」按钮，一键打乱座位。
- **位置调整**：**点选两人互换**（点座位 A 再点座位 B，两者交换）。

## 11. 视觉主题（和风，浅色优先）

| 用途 | 色值 |
|---|---|
| 底色 | 象牙白 `#f5f0e6` |
| 绿呢（桌布） | 绿呢绿 `#2f6b4f` |
| 强调（庄家/立直/结算） | 朱赤 `#c0392b` |
| 领先高亮 | 金 `#d4a017` |
| 正文 | 深墨 `#2c2c2c` |
| 次要文字 | 灰 `#7a746a` |

深色模式：v1 不做，后续可加。

## 12. 排版（字体层级）

字号/块区全量采用**流式 `clamp()`+`vmin`**，随视口连续缩放（屏幕越大字号越大）；`@media` 断点仅做结构（pad 绿呢铺满、sheet 宽）。下表中「手机」≈390px 视口、「pad」≈768px。

| 元素 | 字号/字重（clamp；手机 → pad） |
|---|---|
| 座风（居中） | clamp(18px, 5.2vmin, 34px) / 800（~20 → ~34） |
| 名称（左上角） | clamp(15px, 3.7vmin, 21px) / Regular |
| 点数（座位） | clamp(21px, 5.8vmin, 39px) / 800（~22 → ~39） |
| 分差 | clamp(13px, 3vmin, 18px) / 600 |
| 座位结算按钮 | clamp(16px, 3.9vmin, 23px) / 700 |
| 场风局数（中央） | clamp(25px, 6.9vmin, 46px) / 800（~27 → ~46） |
| 模式·局数（中央） | clamp(11px, 2.4vmin, 14px) / 600 |
| 本场 / 立直棒（中央） | clamp(14px, 3.2vmin, 20px) / Regular |
| 公共按钮（返回/终局/罚符） | clamp(15px, 3.6vmin, 21px) / 700 |
| 骰子（中央） | clamp(32px, 8vmin, 55px)（~32 → ~55） |
| 骰点 | clamp(7px, 2vmin, 14px) |
| 流局按钮（中央） | clamp(16px, 3.9vmin, 25px) / 700 |

> 注：座位条带内容随位置旋转后，实际可视字号相对较小，需在真机尺寸下校验可读性；左右竖条较窄时按钮 `white-space:nowrap` 可能溢出，真机若溢出可降级该档按钮 padding。

## 13. 交互状态汇总

| 操作 | 行为 |
|---|---|
| 点素点数字 | 切换立直状态，供托 ±1 立直棒 |
| 点座位「荣和/自摸」 | 预选该座位并弹对应结算面板 |
| 点中央「罚符」 | 弹罚符面板（面板内选被罚雀士 + 罚点数） |
| 点中央「流局」 | 弹流局面板 |
| 点中央「终局」 | 弹确认框 → 打开「对局结束」面板 |
| 点中央「返回」（进行中） | 显示底部标签栏（仍停留计分风盘） |
| 换庄 | 自风标签旋转，庄家红框移动，座位不跳 |
| 点选两人 | 座位互换（开局调整时） |
| 点「随机」 | 打乱座位（开局时） |
