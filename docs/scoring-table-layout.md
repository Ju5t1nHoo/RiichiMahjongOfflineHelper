# 计分风盘 — 布局与排版设计

> 版本 v0.3，经需求分析访谈确认。配套：`docs/requirements.md`（功能规格）、`CONTEXT.md`（术语）。

## 1. 设计目标

- **一眼读出「谁领先、谁是庄、现在第几局」**：点数、庄家、场风局数是最高优先级信息。
- **结算快**：结算是最频繁操作，入口常驻、大、拇指可达。
- **方位直觉**：环形布局天然对应东南西北，换庄时不让人「跳」。
- **等空间 + 文字朝外**：四个雀士占位完全相同；每张卡按位置旋转，文字朝向各自玩家（手机平放牌桌中央的记分本形态）。
- **移动端竖屏优先**，大按钮大数字，适配线下打牌场景。

## 2. 布局结构

**3×3 九宫格 + 旋转**：四座位各占一格（尺寸完全相同、紧贴中央方块）、中央一格放公共牌局信息、四角留空（绿呢），底部常驻四个结算按钮（荣和/自摸/流局/罚符），顶部细顶栏。

```
┌────────────────────────────────┐
│ ← 四人 · 半庄战           [⋮]  │  顶栏
├────────────────────────────────┤
│   ·        ┌────────┐       ·  │
│   ·        │上席 180°│       ·  │
│            └────────┘           │
│  ┌────────┐  东2局   ┌────────┐ │
│  │左席-90° │  2本场   │右席 90° │ │
│  │         │  供托 0  │        │ │
│  └────────┘          └────────┘ │
│            ┌────────┐           │
│            │下席  0° │           │
│            └────────┘           │
│   ·        ·        ·        ·  │  四角留空（绿呢）
├────────────────────────────────┤
│          ┌──────────┐           │
│          │   结算    │           │  底部主按钮
│          └──────────┘           │
└────────────────────────────────┘
```

### 2.1 响应式尺寸（正方形拉满）

风盘整体为**正方形**，尺寸取「可用区域」内能容纳的最大正方形，任何方向都尽量拉满：

- **边长 = min(可用宽度, 可用高度)**，居中。
- 竖屏：受宽度限制（左右到边、上下留白）；横屏/平板：受高度限制（上下到边、左右留白）。
- **四周留白 = 象牙白底**，绿呢只覆盖正方形本身（不铺满整个中间区域）。
- 尺寸按真实可用空间计算，不依赖固定像素预算；高度用动态视口单位（`dvh`），避免手机浏览器工具栏遮挡底部结算栏。

> 实现：`.score` 内 `.table-area`（`flex:1`）作为正方形容器，`.table` 以 `width: min(100cqw, 100cqh)` 保持正方形并拉满。

## 3. 座位模型

- **等空间**：四个座位占位完全相同（九宫格各占一格）。
- **座位固定**：四个屏幕座位（上/右/下/左）固定对应桌子的四个物理方位。
- **文字旋转**：每张座位卡按位置旋转，文字朝外朝向该玩家——下 `0°`、右 `−90°`、上 `180°`、左 `90°`。
- **标签旋转**：换庄时只有「自风标签」在座位间旋转、庄家徽章跟着走；**人不跳**。
- **无「我」视角**：四方位客观固定；谁坐哪由开局「位置调整 / 随机分位」确定。

## 4. 座位卡

每张卡片信息按重要性排布（卡片整体随位置旋转）：

```
  [东] [庄]            ← 自风标签 + 庄家徽章（仅庄家显示）
  🖼 雀士名             ← 头像 + 名称（同一行，防止长名被挡）
  ─────────────
       +3000           ← 对家分差（小字，+领先 / −落后）
  -1200 25000 +500     ← 上家分差 · 素点 · 下家分差（小字 + 大字）
```

- 自风标签：`东 / 南 / 西 / 北`，换庄时旋转。
- 庄家徽章：仅当前庄家显示「庄」。
- 头像：小圆头像（雀士自定义头像）。
- 点数：素点，大号粗体，最高视觉权重。
- **分差**：围绕素点的小字，`我 − 对方`；对家在上、上家在左、下家在右（三人局无对家、只显示左右；二人局只有对家、只显示上方）。`+` 领先、`−` 落后、相等 `0`。
- **立直按钮：随卡片一起翻转**（文字与大小跟随座位方向）。

## 5. 中央区

中央一格显示当前牌局公共状态（信息方块同为**方形**，与座位卡一致）：

```
      东2局          ← 大字「场风 + 局数」
  2本场 · 供托 3     ← 小字：本场数 · 供托
```

- 只显示**立直棒数**与**本场棒数**，不显示「本场数」。

## 6. 顶栏

- 左：返回（退出/保存提示）。
- 中：`游戏模式 · 局数类型`（如 `四人 · 半庄战`）。
- 右：菜单 `⋮`（结束本局 / 保存 / 规则 / 设置）。

## 7. 结算入口

- 底部常驻一排**四个按钮**：`荣和 / 自摸 / 流局 / 罚符`，直接点选进入各自详情（无中间「结算」按钮）。

## 8. 状态与高亮

| 状态 | 表现 |
|---|---|
| 庄家 | 「庄」徽章 + 座位卡片边框高亮（朱赤） |
| 立直中 | 座位显示红色立直棒图标，供托自动 +1 根 |
| 结算选中 | 被选中的和牌者/放铳者座位高亮 |

## 9. 三人 / 二人适配

- **三人**：上 / 右 / 左 三格（去正下方），旋转 `180° / −90° / 90°`（无 0° 座位）。
- **二人**：上 / 下 两格，旋转 `180° / 0°`。
- 中央、顶栏、结算按钮不变；四角与空位留空（绿呢）。

## 10. 位置调整 / 随机分位（开局时）

- **随机分位**：一个「随机」按钮，一键打乱座位。
- **位置调整**：**点选两人互换**（点座位 A 再点座位 B，两者交换）。

## 11. 视觉主题（和风，浅色优先）

| 用途 | 色值 |
|---|---|
| 底色 | 象牙白 `#f5f0e6` |
| 中央牌桌 | 绿呢绿 `#2f6b4f` |
| 强调（庄家/立直/结算） | 朱赤 `#c0392b` |
| 领先高亮 | 金 `#d4a017` |
| 正文 | 深墨 `#2c2c2c` |
| 次要文字 | 灰 `#7a746a` |

深色模式：v1 不做，后续可加。

## 12. 排版（字体层级）

| 元素 | 字号/字重 |
|---|---|
| 场风局数（中央） | 26px / Bold |
| 点数（座位） | 18px / Bold |
| 结算按钮 | 18px / Medium |
| 名称 | 13px / Regular |
| 本场·供托（中央） | 12px / Regular |
| 顶栏 | 14px / Medium |
| 自风标签 / 庄徽章 | 10px / 徽章 |

> 注：座位卡内容随卡片旋转后，实际可视字号相对较小，需在真机尺寸下校验可读性。

## 13. 交互状态汇总

| 操作 | 行为 |
|---|---|
| 点「立直」 | 切换立直状态，供托 ±1 立直棒 |
| 点「结算」 | 弹出四选一面板 |
| 换庄 | 自风标签旋转，庄家徽章移动，座位不跳 |
| 点选两人 | 座位互换（开局调整时） |
| 点「随机」 | 打乱座位（开局时） |
