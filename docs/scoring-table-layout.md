# 计分风盘 — 布局与排版设计

> 版本 v0.12。配套：`docs/requirements.md`（功能规格）、`CONTEXT.md`（术语）。
> v0.12 变更：响应式适配——上下条带随内容自适应、左右条带 `1fr` 弹性宽度，各尺寸不溢出；左右宽与上下高一致改为非硬性要求。

## 1. 设计目标

- **一眼读出「谁领先、谁是庄、现在第几局」**：点数、庄家、场风局数是最高优先级信息。
- **结算快**：结算是最频繁操作，每个座位自带「荣和/自摸/罚符」按钮，点即预选该座位并进入结算。
- **方位直觉**：环绕布局（上/左/下/右围中央）天然对应东南西北，换庄时不让人「跳」。
- **文字朝外**：每个座位条带按位置旋转，文字朝向各自玩家（手机平放牌桌中央的记分本形态）。
- **移动端竖屏优先**，大按钮大数字，适配线下打牌场景。

## 2. 布局结构

**环绕条带 + 中央块区**：绿呢平铺整个风盘界面（无四周留白、无正方形约束）。上/下为全宽横条，左/右为竖条，中央块区放公共信息与「流局」；顶部一条顶栏。

```
┌────────────────────────────────┐
│ ← 四人 · 半庄战          [终局] │  顶栏
├────────────────────────────────┤
│     上家 (180°) 横条            │
│  名·点 · [立直][荣和][自摸][罚符] │
├──────┬───────────────┬─────────┤
│ 左家  │   东2局 · 2本场  │  右家  │
│ 90°  │    供托 · 骰子    │ −90°  │
│ 竖条  │     [流局]       │  竖条  │
├──────┴───────────────┴─────────┤
│     下家 (0°) 横条             │
│  名·点 · [立直][荣和][自摸][罚符] │
└────────────────────────────────┘
```

### 2.1 全屏铺满

- 牌局**进行中自动隐藏底部标签栏**（沉浸式）；开局页与终局后仍显示标签栏。进行中顶栏左「返回」键重新显示标签栏、仍停留在计分风盘。
- 绿呢铺满整个风盘界面，四周无边距；尺寸按真实视口计算（`dvh`），不依赖固定像素预算。
- 上/下条带横向拉伸铺满整行（高度随内容自适应）；左/右为竖条（`1fr` 弹性宽度）；不再保持正方形。

## 3. 座位模型

- **座位固定**：四个屏幕座位（上/右/下/左）固定对应桌子的四个物理方位。
- **文字旋转**：整条随位置旋转——下 `0°`、右 `−90°`、上 `180°`、左 `90°`（文字/按钮朝外朝向该玩家）。
- **标签旋转**：换庄时只有「自风标签」在座位间旋转、庄家徽章跟着走；**人不跳**。
- **无「我」视角**：四方位客观固定；谁坐哪由开局「位置调整 / 随机分位」确定。

## 4. 座位条带

每条带内容（整体随位置旋转）分三段：座风与玩家信息、分数分差、底部按钮。

```
         [东]                ← 座风标识（东即庄家）
       🖼 雀士名              ← 玩家信息（在座风下方）
         +3000               ← 对家分差（小字，+领先 / −落后）
  -1200  25000  +500         ← 分数 + 分差居中（大号）
  [荣和]  [自摸]  [罚符]        ← 底部：结算按钮（三等分平铺）
```

- 自风标签：`東 / 南 / 西 / 北`（繁体），换庄时旋转；**東即庄家**，不另设庄家徽章（庄家仅以卡片红框高亮识别）。
- 玩家信息：头像 + 名称，置于座风标识下方。
- 点数：素点，大号粗体、居中，最高视觉权重。
- **分差**：围绕素点的小字，`我 − 对方`；对家在上、上家在左、下家在右（三人局无对家、只显示左右；二人局只有对家、只显示上方）。`+` 领先、`−` 落后、相等 `0`；变化带滚动数字动画。
- **结算按钮**：荣和 / 自摸 / 罚符，底部三等分平铺、各占 1/3 宽度（间隔防误触）。
- **立直**：点击素点数字切换立直状态，供托 ±1 立直棒；立直时**块区背景变蓝**（`#3b82f6`）、名称/分数/分差文字变白。

## 5. 中央区

中央块区显示当前牌局公共状态 + 整桌操作：

```
      东2局          ← 大字「场风 + 局数」
  2本场 · 供托 3     ← 小字：本场数 · 供托
      ⚀ ⚁           ← 骰子（点击掷）
      [流局]         ← 流局按钮（整桌结果）
```

- 只显示**立直棒数**与**本场棒数**，不显示「本场数」。
- **流局**放这里：流局是整桌结果（无人和牌）、无座位归属，与终局区分开。

## 6. 顶栏

顶栏仅在牌局进行中显示（开局页标签栏可见即可导航，无需顶栏）。

- 左：`←` 返回（显示底部标签栏，仍停留计分风盘）。
- 中：`游戏模式 · 局数类型`（如 `四人 · 半庄战`）。
- 右：`终局` 按钮（点击弹确认框 → 打开「对局结束」面板；登录用户在面板内点「终局并保存」落库、游客「关闭」）。
- （`⋮` 菜单：保存 / 规则 / 设置，暂未实现。）

## 7. 结算入口

- **每座位自带三个按钮**：`荣和 / 自摸 / 罚符`，点击 = 预选该座位并弹对应面板（省一次点选）：
  - 自摸 → 该座位预选为和牌者，面板里点「番符」字段选番符。
  - 罚符 → 该座位预选为被罚者，面板里选罚点数。
  - 荣和 → 该座位预选为**和牌者**，面板里再选放铳者 + 番符；多家荣和在面板里各自选番符。
- **番符得点表**：点「番符」字段弹出表格——番 1~4 为「符行 × 番列」网格（格内分数），满贯封顶的符按番合并为「满贯」一格（边界随切上满贯开关）；下方满贯档位区（5番满贯 / 6~7番跳满 / 8~10番倍满 / 11~12番三倍满 / 13番役满 / 26番双倍役满）。表格自动区分亲/子、荣/自摸：荣和单数、亲家自摸 `X all`、子家自摸 `X,Y`（子付,亲付）；荣和隐藏 20符行，20符/25符的 1番显示 `-` 不可选。
- **流局** → 中央块区按钮，弹流局面板（不听罚符 / 途中流局 / 流局满贯）。
- **面板随座位旋转**：三按钮面板与「番符得点表」均按触发座位旋转（上 180°/左 90°/下 0°/右 −90°），与卡片方位一致；流局面板（中央触发）不旋转。
- 不再有底部共享四选一结算栏。

## 8. 状态与高亮

| 状态 | 表现 |
|---|---|
| 庄家 | 座位条带边框高亮（朱赤）；东即庄家，不设庄家徽章 |
| 立直中 | 块区背景变蓝（#3b82f6）、文字变白，供托自动 +1 根 |
| 结算选中 | 被选中的和牌者/放铳者座位高亮 |

## 9. 三人 / 二人适配

- **三人**：上 / 左 / 右（去正下方），旋转 `180° / 90° / −90°`（无 0° 座位）。
- **二人**：上 / 下，旋转 `180° / 0°`。
- 中央、顶栏、流局按钮不变；空位留绿呢。

## 10. 位置调整 / 随机分位（开局时）

- **随机分位**：一个「随机」按钮，一键打乱座位。
- **位置调整**：**点选两人互换**（点座位 A 再点座位 B，两者交换）。

## 11. 视觉主题（和风，浅色优先）

| 用途 | 色值 |
|---|---|
| 底色 | 象牙白 `#f5f0e6` |
| 绿呢（桌布） | 绿呢绿 `#2f6b4f` |
| 强调（庄家/立直/结算） | 朱赤 `#c0392b` |
| 领先高亮 | 金 `#d4a017` |
| 正文 | 深墨 `#2c2c2c` |
| 次要文字 | 灰 `#7a746a` |

深色模式：v1 不做，后续可加。

## 12. 排版（字体层级）

| 元素 | 字号/字重 |
|---|---|
| 场风局数（中央） | 22px / Bold |
| 点数（座位） | clamp(16px, 4vmin, 26px) / Bold |
| 座位结算按钮 | 15px / Bold |
| 流局/终局按钮 | 13–14px / Bold |
| 名称 | 15px / Regular |
| 本场·供托（中央） | 12px / Regular |
| 顶栏 | 14px / Medium |
| 自风标签 | 13px / 徽章 |

> 注：座位条带内容随位置旋转后，实际可视字号相对较小，需在真机尺寸下校验可读性。

## 13. 交互状态汇总

| 操作 | 行为 |
|---|---|
| 点素点数字 | 切换立直状态，供托 ±1 立直棒 |
| 点座位「荣和/自摸/罚符」 | 预选该座位并弹对应结算面板 |
| 点中央「流局」 | 弹流局面板 |
| 点顶栏「终局」 | 弹确认框 → 打开「对局结束」面板 |
| 点顶栏「返回」（进行中） | 显示底部标签栏（仍停留计分风盘） |
| 换庄 | 自风标签旋转，庄家红框移动，座位不跳 |
| 点选两人 | 座位互换（开局调整时） |
| 点「随机」 | 打乱座位（开局时） |
