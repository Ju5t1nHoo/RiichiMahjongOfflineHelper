# 数据统计 — 布局与排版设计

> 版本 v0.1，经需求分析访谈确认。配套：`docs/requirements.md` §6（功能规格）、`CONTEXT.md`（术语）。

## 1. 设计目标

- **一块一意图**：我的创建（我建了什么）/ 数据广场（大家玩了什么）/ 雀士数据（谁最强）三种意图，用顶层 Tab 分开。
- **模式是过滤器**：四人/三人/二人对所有块都是内容过滤器，放块内顶部，不抬成主导航。
- **排行榜快扫、详情深看**：排行榜行只留关键指标，全量指标进雀士详情页。
- **视觉与计分风盘一致**：复用同一套和风配色与字体层级，用户不重新学习。

## 2. 信息架构

```
数据统计
├── 我的创建      [四人|三人|二人]   → 牌局详情（共用）
├── 数据广场      [四人|三人|二人]   → 牌局详情（共用）
└── 雀士数据      [四人|三人|二人]   → 雀士详情页
```

顶层三个 Tab 并列；每个块内顶部一个「四人 / 三人 / 二人」分段控件（默认四人）。牌局详情页为「我的创建」与「数据广场」共用。

## 3. 通用框架

每个块页共用一个外壳：顶栏 + 模式分段控件 + 内容区。

```
┌────────────────────────────────┐
│ ← 数据统计                      │  顶栏（返回 + 标题）
├────────────────────────────────┤
│  [ 四人 ]  [ 三人 ]  [ 二人 ]   │  模式分段控件（默认四人）
├────────────────────────────────┤
│                                │
│           内容区（列表）        │
│                                │
└────────────────────────────────┘
```

## 4. 我的创建

我作为主机创建的牌局列表，**时间倒序**，含「进行中」与「已终局」两类。

```
┌────────────────────────────────┐
│ [进行中]  四人 · 半庄战          │
│ 张三 · 李四 · 王五 · 赵六       │
│ 开始于 09-02 20:10             │   ← 点击恢复进计分风盘
├────────────────────────────────┤
│ 09-01 18:40  四人               │
│ 张三 · 李四 · 王五 · 赵六       │
│ 1位 张三 +45.5 · 2位 李四 +8.0  │   ← 点击进牌局详情
├────────────────────────────────┤
│ 08-30 14:05  三人               │
│ ...                            │
└────────────────────────────────┘
```

- 进行中卡片带「进行中」角标（朱赤），点击 → 恢复进计分风盘继续。
- 已终局卡片显示结束时间 + 模式 + 参与雀士 + 终局顺位摘要（前 1~2 位 + 得点），点击 → 牌局详情。
- 空态：提示「还没有创建过牌局」。

## 5. 数据广场

所有已终局牌局，时间倒序公开；无搜索/筛选（本期）。

```
┌────────────────────────────────┐
│ 09-01 18:40  四人               │
│ 主机：张三                      │
│ 张三 · 李四 · 王五 · 赵六       │
│ 1位 张三 +45.5 · 2位 李四 +8.0  │   ← 点击进牌局详情
├────────────────────────────────┤
│ 09-01 15:12  三人               │
│ 主机：李四                      │
│ ...                            │
└────────────────────────────────┘
```

- 卡片比「我的创建」多一行「主机名」（因为是他人创建的局）。
- 点击 → 牌局详情（共用）。
- 空态：提示「还没有公开牌局」。

## 6. 牌局详情（共用）

「我的创建」已终局牌局与「数据广场」牌局共用此页。

```
┌────────────────────────────────┐
│ 四人 · 半庄战 · 09-01 18:40     │  概要
│ 主机：张三                      │
├────────────────────────────────┤
│  终局顺位                       │
│  1位  张三  35600  +45.5        │
│  2位  李四  30200  +8.0         │
│  3位  王五  28800  -1.2         │
│  4位  赵六  24400  -52.3        │
├────────────────────────────────┤
│  分数走势（折线图）             │
│  ▲ 张三  ▲ 李四  ▲ 王五  ▲ 赵六 │
│  开局 → 逐局 → 终局            │
├────────────────────────────────┤
│  逐局结算                       │
│  东1局  张三 荣和 8000           │
│  东2局  流局（不听罚符）         │
│  ...                            │
└────────────────────────────────┘
```

- 顶部概要：模式 · 局数类型 · 结束时间 + 主机名。
- 终局顺位表：1~N 位，雀士名 + 素点 + 得点（保留一位小数，按设置）。
- 逐局结算记录：局序号 + 结果类型（荣和/自摸/流局/罚符）+ 点数变动摘要，时间正序。
- 分数走势：简易折线图（每家一条折线，开局基准分 → 逐局 → 终局素点；无依赖内联 SVG）。

## 7. 雀士数据（排行榜）

排行榜 + 详情页两层。顶部搜索 + 排序切换。

```
┌────────────────────────────────┐
│ [ 🔍 搜索雀士 ]   [我的雀士]    │  搜索 + 快捷筛选
│ 排序：总得点 ▾                   │  排序切换
├────────────────────────────────┤
│  1  🖼 张三    +455.0            │
│         局数 38 · 平均顺位 1.72 │
│  2  🖼 李四    +320.5            │
│         局数 41 · 平均顺位 1.95 │
│  2  🖼 王五    +320.5            │   ← 并列同名次
│         局数 30 · 平均顺位 2.00 │
└────────────────────────────────┘
```

- 排序：总得点降序（默认）/ 平均顺位升序 / 牌局数降序；并列取同名次。
- 每行主行：排名 + 头像 + 名称 + 当前排序指标值；副行：牌局数 + 平均顺位（两小字）。
- 搜索：按雀士名匹配；「我的雀士」快捷筛选出自己绑定的雀士。
- 默认仅显示有牌局数记录的雀士；支持分页。

## 8. 雀士详情页

点击排行榜行进入，展示全量指标 + 顺位分布。

```
┌────────────────────────────────┐
│  🖼  张三      （我绑定的雀士）  │  头部
├────────────────────────────────┤
│  牌局数 38    总得点 +455.0      │
│  净得点 +180.2  平均顺位 1.72   │
│  击飞次数 1                     │
├────────────────────────────────┤
│  顺位分布                       │
│  1位 ████████████ 24            │
│  2位 ██████ 10                  │
│  3位 ███ 3                      │
│  4位 █ 1                        │
├────────────────────────────────┤
│  和牌率 25.0%   自摸率 42.1%    │
│  荣和数 12      放铳率 13.2%    │
│  立直率 18.4%   平均番数 4.8    │
└────────────────────────────────┘
```

- 头部：头像 + 名称 + 绑定归属提示（「我绑定的雀士」/ 他人雀士）。
- 牌局级指标：牌局数、总得点、净得点、平均顺位、击飞次数。
- 顺位分布：横向条形（绿呢色填充，长度按次数），按四人/三人/二人对应 4/3/2 位。
- 手级指标：和牌率、自摸率、荣和数、放铳率、立直率、平均番数（百分比保留一位小数）。

## 9. 视觉主题

复用计分风盘（`scoring-table-layout.md` §11）的同一套配色：

| 用途 | 色值 |
|---|---|
| 底色 | 象牙白 `#f5f0e6` |
| 强调（进行中角标 / 选中） | 朱赤 `#c0392b` |
| 图表填充（顺位分布） | 绿呢绿 `#2f6b4f` |
| 领先 / 排名第一 | 金 `#d4a017` |
| 正文 | 深墨 `#2c2c2c` |
| 次要文字 | 灰 `#7a746a` |

## 10. 排版

| 元素 | 字号/字重 |
|---|---|
| 页面标题（顶栏） | 16px / Medium |
| 模式分段控件 | 14px / Medium |
| 卡片主行（雀士名 / 排序值） | 15px / Medium |
| 卡片副行（局数 / 平均顺位） | 12px / Regular |
| 顺位表名次 | 15px / Bold |
| 指标数值（详情页） | 18px / Bold |
| 指标标签 | 12px / Regular |

## 11. 交互状态汇总

| 操作 | 行为 |
|---|---|
| 切模式分段控件 | 切换当前块的内容（四人/三人/二人） |
| 点「进行中」卡片 | 恢复进计分风盘 |
| 点「已终局」卡片 | 进牌局详情 |
| 点排行榜行 | 进雀士详情页 |
| 切排序键 | 总得点/平均顺位/牌局数 重排（并列同名次） |
| 搜索雀士 | 按名称过滤排行榜 |
| 点「我的雀士」 | 只看自己绑定的雀士 |
