# 个人中心 — 布局与排版设计

> 版本 v0.1，经需求分析访谈确认。配套：`docs/requirements.md` §7（功能规格）、`CONTEXT.md`（术语）。

## 1. 设计目标

- **hub + 子页**：个人中心是一个「资料 hub」，管理类功能（雀士/规则/密码/反馈）各自进子页，主页面保持清爽。
- **未登录有门面**：游客打开个人中心看到登录/注册页，不看到空列表。
- **视觉一致**：复用计分风盘/数据统计同一套和风配色与字体层级。

## 2. 信息架构

```
个人中心（登录后）
├── 资料头（文字头像 + 用户名 + 签名）
├── 雀士管理        → 我的雀士 / 创建 / 绑定雀士
├── 规则默认设置    → 四人|三人|二人 × 12 参数
├── 修改密码
├── 意见反馈
└── 退出登录

个人中心（未登录）
└── 登录 / 注册
```

## 3. 登录 / 注册页（未登录态）

未登录打开个人中心，显示登录/注册（用分段或切换在登录与注册间切换）。

```
┌────────────────────────────────┐
│         立直麻将计分            │  标题
│                                │
│  [ 登录 ]  [ 注册 ]             │  切换
│                                │
│  用户名  [________________]    │
│  密码    [________________]    │
│  （注册时）确认密码 [________] │
│                                │
│      [        登录        ]     │
└────────────────────────────────┘
```

- 登录：用户名 + 密码。
- 注册：用户名 + 密码 + 确认密码。
- 无邮箱/手机、无找回密码、无第三方登录（v1）。

## 4. 个人中心 hub（登录后）

```
┌────────────────────────────────┐
│ ← 个人中心                     │
├────────────────────────────────┤
│  🖼  用户名                     │  ← 文字头像（用户名首字）
│  个性签名：xxxx（点此编辑）      │
├────────────────────────────────┤
│  > 雀士管理                     │
│  > 规则默认设置                 │
│  > 修改密码                     │
│  > 意见反馈                     │
├────────────────────────────────┤
│         [ 退出登录 ]            │
└────────────────────────────────┘
```

- 资料头：文字头像（用户名首字 + 主题色圆）+ 用户名 + 个性签名。
- 点签名 → 编辑签名子页。
- 底部「退出登录」→ 回未登录态。

## 6. 雀士管理

两段式：我的雀士列表 + 绑定雀士入口。

```
┌────────────────────────────────┐
│ ← 雀士管理            [+ 创建]  │
├────────────────────────────────┤
│  我的雀士                       │
│  🖼 张三      [编辑] [解绑]      │
│  🖼 李四      [编辑] [解绑]      │
├────────────────────────────────┤
│  [ 绑定雀士 ]                   │
└────────────────────────────────┘
```

- **创建雀士**（子页）：名称 + 头像上传（jpg/png ≤ 2MB，预览），创建即绑定给我。
- **编辑**（子页）：改名称/头像，仅限自己绑定的雀士。
- **绑定雀士**（子页）：全局搜索，列出**未绑定**的雀士，点「绑定」获得所有权（支持绑定他人已解绑的雀士）。
- 解绑：释放所有权，雀士仍在全局注册表。

## 7. 规则默认设置

顶部模式分段 + 一套 12 参数表单，每模式独立保存。

```
┌────────────────────────────────┐
│ ← 规则默认设置                  │
│ [ 四人 ] [ 三人 ] [ 二人 ]      │
├────────────────────────────────┤
│  局数         [ 半庄战 ▾ ]     │
│  基础分       [ 25000 ]         │
│  返点         [ 30000 ]         │
│  本场点棒     [ 300 ]           │
│  不听罚符     [ 3000 ]          │
│  不满返点延局 [ 是 ⚫ 否 ]       │
│  番缚         [ 一番缚 ▾ ]      │
│  切上满贯     [ 是 ⚫ 否 ]       │
│  击飞         [ ⚫ 是 否 ]       │
│  终局第一无限连庄 [ 是 ⚫ 否 ]   │
│  马点         [ 10-5 ▾ ]        │
│  得点保留一位小数 [ ⚫ 是 否 ]    │
├────────────────────────────────┤
│         [ 恢复默认 ]            │
└────────────────────────────────┘
```

- 参数与默认值见 `requirements.md` §5 表。
- 控件类型：数字（基础分/返点/本场点棒/不听罚符）、选择（局数/番缚/马点）、开关（其余五个布尔项）。
- 「恢复默认」重置当前模式到 §5 默认值。

## 10. 视觉主题

复用计分风盘（`scoring-table-layout.md` §11）的同一套配色：

| 用途 | 色值 |
|---|---|
| 底色 | 象牙白 `#f5f0e6` |
| 强调（主按钮/选中/文字头像） | 朱赤 `#c0392b` |
| 文字头像 / 图表 | 绿呢绿 `#2f6b4f` |
| 正文 | 深墨 `#2c2c2c` |
| 次要文字 | 灰 `#7a746a` |
| 卡片底 | `#fffdf7` |

## 11. 排版

| 元素 | 字号/字重 |
|---|---|
| 页面标题（顶栏） | 16px / Medium |
| 用户名 | 17px / Bold |
| 子项入口 / 表单标签 | 15px / Regular |
| 输入框文字 | 15px / Regular |
| 主按钮 | 16px / Medium |
| 次要说明（签名/字数） | 12px / Regular |

## 12. 交互状态汇总

| 操作 | 行为 |
|---|---|
| 未登录打开 | 显示登录/注册页 |
| 点签名 | 进编辑签名子页 |
| 点「+ 创建雀士」 | 进创建子页（名称 + 头像上传） |
| 点雀士「编辑」 | 进编辑子页（仅限自己绑定的） |
| 点雀士「解绑」 | 确认后解绑（释放所有权） |
| 点「绑定雀士」 | 进全局搜索，点未绑定雀士的「绑定」 |
| 切模式分段 | 切换当前模式的 12 参数表单 |
| 点「恢复默认」 | 重置当前模式参数到默认值 |
| 点「退出登录」 | 回未登录态 |
